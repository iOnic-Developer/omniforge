## Reproduce

From the repository root, with existing dependencies and Chromium installed (the script installs nothing):

```sh
node scripts/capture-product.mjs
```

Defaults: Python at `.venv/bin/python`, local Playwright import, then the existing workspace Playwright at `/workspace/omniforge/node_modules/playwright/index.mjs`. For this docs worktree, use:

```sh
OMNIFORGE_CAPTURE_PYTHON=/workspace/omniforge/.venv/bin/python \
OMNIFORGE_CAPTURE_PLAYWRIGHT=/workspace/omniforge/node_modules/playwright/index.mjs \
node scripts/capture-product.mjs
```

Both overrides can point to equivalent existing local installations elsewhere. No dependency installs, external data calls, production databases or credentials are used. Python and Node examples execute as real app subprocesses with temporary SQLite, library, home and scratch directories and an explicit environment allowlist; inherited secrets are excluded. The temporary server binds only to loopback. Browser requests outside its origin are blocked and asserted to be zero. Browser and server close and temporary data is removed in finally.
