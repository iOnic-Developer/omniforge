    New Tool

    1

    Plain-text code editor with line numbers. Tab indents; Shift+Tab unindents selected lines. Escape, then Tab leaves the editor.

    Tool settings

    Python: requests or requests==2.32.5. Node: lodash or lodash@4.17.21; scoped names supported. Installs on first run into a persistent cache, not on save.

    Tips

    Save before testing. Print JSON with Python print() or Node console.log(). Run / Test executes the saved script with empty inputs.

    Only run trusted scripts. Built-in MCP authoring tools are always available and cannot be toggled here.

    Help and examples

    1. Use New tool, enter a name, language, description and code, then Save.
    2. Run / Test executes saved code; save edits first. Results and errors appear below the editor.
    3. Enabled scripts appear in MCP discovery. Disable hides discovery, not the dashboard or manual testing. Refresh your client's tool list after changes.

    Install examples saves the four missing examples after confirmation; existing names are never overwritten. It does not install packages. Load example below only changes the editor until you Save.

    Packages and safety

    Package names, one per line: Python requests or requests==2.32.5; Node lodash or lodash@4.17.21 (scoped names supported). First run installs into a persistent per-tool cache (up to 120 seconds); later runs reuse it. No URLs, commands, system binaries, source builds or npm install scripts. Saving alone does not install. CommonJS require() is supported for Node packages.

    Scripts share the application container. Dashboard/API authentication is not implemented: keep this service on a trusted network. Config shows connection metadata, never the API key.
