  1. Choose a no-package Python or Node template below.
  2. Give it a unique name and save. Saving never runs code.

Saves the four examples. Existing names are skipped; no scripts execute.
Write for a predictable result
Print JSON using print(json.dumps(...)) in Python or console.log(JSON.stringify(...)) in Node. Returning an object alone doesn’t produce output.
MCP arguments arrive as one JSON object on stdin. Enter a JSON object in Test inputs to try required arguments in the browser. The server validates it against the saved input schema before execution; use {} only when no inputs are required.
Disabled tools remain saved in your library but are hidden from MCP discovery. Built-in helper names are reserved.
When something goes wrong
Save changes before running. If the name is taken, choose a new one. For package failures, check names and exact versions; source builds, lifecycle scripts and system binaries aren’t supported.
First-time installs can take up to 120 seconds plus a bounded lock wait. Script timeout starts after installation and currently adds 15 seconds to the configured duration.
Only trusted scripts and dependencies belong here. Memory limits, process-tree termination and output caps are not implemented.
Take your workspace with you
On eligible HTTPS browsers, use Install app when it appears. On iPhone or iPad, open in Safari, use Share, then Add to Home Screen. Other browsers may offer installation in their menu.
An HTTP LAN address usually isn’t eligible for service workers or installation. Use HTTPS; localhost is allowed for development.
This is an online workspace. Saving, installing packages and executing tools always require the server. Offline, you’ll see a safe reconnect page — never cached scripts or results.
