    Packages and safety

    Package names, one per line: Python requests or requests==2.32.5; Node lodash or lodash@4.17.21 (scoped names supported). First run installs into a persistent per-tool cache (up to 120 seconds); later runs reuse it. No URLs, commands, system binaries, source builds or npm install scripts. Saving alone does not install. CommonJS require() is supported for Node packages.

    Scripts share the application container. Dashboard/API authentication is not implemented: keep this service on a trusted network. Config shows connection metadata, never the API key.
